# Images

Drop the chapel photos in this folder using these exact filenames (lowercase):

| File | Used by | Suggested size |
| --- | --- | --- |
| `hero.jpg` | Hero banner background (`.hero:after` in `style.css`) + social share preview | 1920 x 1080, landscape |
| `sermon.jpg` | Latest Sermon thumbnail (`.placeholder-image:has(.play-button)`) | 800 x 600 |
| `favicon.svg` | Browser tab icon | already provided |

If `hero.jpg` or `sermon.jpg` are missing, the site still renders — the navy/gold
gradient fallback is shown instead.

Keep JPEGs under ~300 KB each so the page stays fast on mobile data.
